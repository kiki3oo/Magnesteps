# 🇲🇦 MagneSteps™ - Landing Page E-commerce COD Maroc

صفحة هبوط احترافية عالية التحويل (High-Converting Landing Page) مخصصة لبيع منتوج **MagneSteps™** بنظام الدفع عند الاستلام (Cash On Delivery) في السوق المغربي.

---

## 📁 محتويات المشروع
* **`index.html`**: صفحة الهبوط الرئيسية للزبون (Mobile-First، باللغة العربية والدارجة المغربية).
* **`admin.html`**: لوحة تحكم وإدارة مبيعات COD محمية برمز سري (تأكيد، اتصال، تتبع، وتصدير إكسيل).
* **`privacy-policy.html`**: صفحة سياسة الخصوصية وحماية المعطيات (وفق القانون 09-08).
* **`terms.html`**: صفحة الشروط والأحكام العامة للبيع والتوصيل (وفق القانون 31-08).
* **`returns.html`**: صفحة سياسة الاسترجاع والاستبدال خلال 7 أيام.
* **`images/`**: مجلد الصور المحلية عالية الجودة بدون أي اعتماد على سيرفورات خارجية.

---

## 🔐 لوحة التحكم الخاصة بك (`admin.html`)
- **الرابط المباشر**: `http://localhost:5500/admin.html`
- **رمز الدخول الافتراضي (PIN)**: `1234`
- **المميزات**:
  1. استقبال الطلبيات الجديدة فورياً ومزامنتها تلقائياً.
  2. أزرار اتصال سريع: 📞 اتصال هاتفي مباشر + 💬 محادثة واتساب بتأكيد فوري بنقرة واحدة.
  3. تغيير حالة الطلبية (En attente, Confirmé, En livraison, Livré, Annulé).
  4. حساب نسب التأكيد (Taux de Confirmation %) والتسليم ومجموع المداخيل بالدرهم.
  5. تصدير مباشر إلى ملف **Excel (CSV)** لتقديمه إلى شركة الشحن (Cathedis, Amana, Ozone...).
  6. إضافة طلبيات يدوية وإدارة الفلترة والبحث.
